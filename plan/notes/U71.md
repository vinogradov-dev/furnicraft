# U71 — Appearance presets and the shared UI design spec

Appearance presets and the shared UI design spec

This note is the shared spec for U64–U71: read it before starting any later UI task.

## Approved decisions (owner)

- Tabs are nouns and name the domain: Эскиз, Модель, Мебель, Сцена, Вид. The old top-level «Изменить» tab is removed; editing belongs to its domain.
- Level four under a tab: group (operation class) → tool (command) → variant (input method). "Окружности" is a tool, not a group.
- All tools of a group are visible; variants of one tool live in its dropdown. Line and polyline are separate tools and both stay on the ribbon.
- Clicking a tool with variants always opens the list (F1); it closes on Esc, outside click and tab change; no footer text.
- Panels float over the scene (M2), 92 % opacity by default; one opacity setting for ribbon, panels and clusters.
- The ribbon folds to its tab row (29 px) and the state persists.
- Fields: number only, 76 px, units in the section header; live apply with a 150 ms debounce; one undo per value; no per-field Apply; a command bar with ✓/✕ for preview operations.
- Status bar: command left, selection context centre, snap/projection/state right.
- The three display sliders are renamed and moved: grid → «Сетка пола», edges → «Контуры», shadow → «Контактная тень»; strengths in Settings → View, toggles in the cluster.

## Metrics (CSS points, 1×)

- header 36; ribbon tab row 28; tool row 30; caption band 12; open ribbon 72; collapsed 29.
- ribbon icon 22; cell 34×30; caption 9.5; group caption in the darker band under the tool row.
- tool list: 298 wide, 30 rows, no footer; flips to right-aligned at the window edge.
- panels: 226 wide, 8 inset, radius 8; collapsed strip 34; opacity 92 % default.
- fields 76×22, right-aligned tabular; status row 26–28.

## Behaviour details

- The ribbon is one shade; the caption band is darker; the list is darker still.
- The open state and the panel states persist in settings.
- The panel buttons live in the tab row so they survive a folded ribbon and hidden panels: collapse all, hide all, fold ribbon.
- Chevrons are neutral panel glyphs pointing toward the collapse edge; the strip shows the mirrored one.
- Status: prompt left, selection context centre (name, kind, size, material, edge banding, count, warnings), snap/projection/state right.
- The mock was `/tmp/furnicraft-ui/variants.html` (ephemeral); its sections were Accepted, Terminology, Status and view, Fields, Panels and customisation. This note, not that file, is the source.

## Ruled out

- A fourth palette P3 and per-preset icon assets: icons take their hue from the semantic family, only neutrals and the accent change.
- Docked opaque panels (M1) as the default: the owner chose M2 and accepted the picking cost.
- The horizontal shelf (F3) for hidden variants: it pushes the scene and reads as a second ribbon.
- Repeat-last-variant click: the owner wants the list to open every time.
- One visible tool per group as a hard rule: `Создать` needs line and polyline together.
