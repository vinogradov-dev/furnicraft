# U64 — Status bar context and the display settings

Status bar context and the display settings

## Zones

| zone | content | source |
|---|---|---|
| left | current command and step, Enter/Esc, transient error or notice | session/editor |
| centre | selection context: kind, name, size, material, edge banding, count, warnings | resolved selection |
| right | snap, projection, zoom/scale, «Готово» / «Перестроение…» | shell/view state |

- One row, 26–28 px; no wrapping, the centre elides with a tooltip.
- The centre shows the count only when more than one node is selected; a single node shows
  `Фасад · панель 600 × 720 × 18 мм · ЛДСП белёный дуб · кромка 2 мм`.
- Warnings (locked node, missing material, invalid contour) render as a chip with the warn colour;
  they never duplicate the card, which keeps the editable fields.
- The summary is a snapshot built once per frame from the selection the session already resolved;
  no document walk, no allocation beyond the formatted line (reuse a buffer if the frame cost shows).
- Future parameters (owner: not defined yet) are new `Option` fields on `StatusSummary` and one
  more chip; the row does not change shape.

## Display sliders — what they do today

- `ViewCluster.grid_strength` (60): brightness of the work-plane floor grid; 0 hides it. It is not
  the snap step: the 10 mm snap is a separate status-bar toggle.
- `ViewCluster.edge_strength` (70): strength of the form-edge outline pass; 0 = fill only.
- `ViewCluster.shadow_strength` (40): strength of the contact shadow.
- `ViewCluster.all_edges`: a diagnostic that draws every triangle edge; not a user setting.
- All four are view state; no value reaches the document.

## Change

- Rename to «Сетка пола», «Контуры», «Контактная тень»; add a one-line tooltip to each.
- The cluster keeps the three on/off switches and a «Настроить…» button; the strengths move to
  Settings → View with a «Сброс» (60/70/40).
- `all_edges` moves under «Дополнительно» in Settings → View, marked as a diagnostic; it disappears
  from the cluster.
- The status-bar snap toggle is labelled «Привязка 10 мм» and the grid brightness is never called
  «Сетка» in the status bar.

## Tests

- single vs multi-selection shapes;
- elision and tooltip;
- busy state text while a rebuild runs;
- settings round-trip for 0/50/100 and reset to 60/70/40;
- the cluster draws no `all_edges` control;
- the status bar label is «Привязка 10 мм»;
- both themes and a 1024 px window are checked by eye.

## Ruled out

- A second information row under the viewport: the status bar is the place.
- Putting the selection context into the card: it would duplicate the fields and grow the card.
- Keeping the raw names «Сетка/Рёбра/Тень»: they collide with snap and edge banding.
