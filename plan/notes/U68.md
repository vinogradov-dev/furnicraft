# U68 — The ribbon spec and the tab map

The ribbon spec and the tab map

## Map (id — group — tools, most used first)

- sketch — Создать: line, polyline, rectangle, circle, arc, polygon (variants in U67).
- sketch — Изменить: trim, extend, offset, fillet, chamfer, break.
- sketch — Опорные: construction-horizontal, construction-vertical, construction-parallel, construction-angle.
- sketch — Размеры: dimension-linear, dimension-angular, dimension-radius.
- sketch — Булевы: boolean-union, boolean-subtract, boolean-intersect.
- model — Примитивы: cube, cylinder, sphere, cone, pyramid (pyramid planned).
- model — Создать: extrude, revolve, loft, sweep (loft/sweep planned).
- model — Булевы: union, subtract, intersect.
- model — Грани: chamfer, fillet, shell, offset-face, delete-face (most planned).
- model — Тела: join, split, scale, mirror.
- furniture — Панели: panel, contour-panel; Обработка: drill, groove, edgeband, hinge-hole;
  Крепёж: confirmat, cam, dowel, minifix, shelf-pin; Фурнитура: hinge, runner, handle, foot;
  Проверка: collisions, parts-list, cut-list. Most planned; draw the tab only when a tool is live.
- scene — Объекты: camera, light, assembly, group; Виды: named-view, standard-view;
  Материалы: catalogue, assign.
- view — Проекция: projection, frame-all; Отображение: style, grid, contours, shadows, section;
  Раскладка: layout-1, layout-2, layout-4, maximize; Навигация: orbit, pan, zoom (gestures).

Ids are `tab.group.tool`; a group name is reused across tabs because the commands differ
(`sketch.boolean.union` vs `model.boolean.union`). A variant id is `tab.group.tool.variant`.

## Current code (measured before the change)

- `RibbonTab` is an enum with `ALL`, `columns()` (hardcoded 0/6/13/4/3), `label`, `id`, `groups`.
- `ToolGroup` is an enum with `ALL`, `label`, `theme`; `show_group_row` matches the group and calls
  `icons::ribbon_button` per tool.
- `ToolAction` carries the click; `RibbonContext` carries availability; `Toolbars` holds open/tab
  and the numeric texts; `height(open)` is 130 px today.
- The cell width is `RibbonMetrics::measure` over `columns()`; with a spec it becomes the maximum
  tool count of any group in any tab.

## Shape

- `spec.rs`: const tables + accessors (`tabs()`, `groups(tab)`, `tools(group)`), no allocation per
  frame.
- `ToolSpec.state: ToolState { Live, Planned }`; planned rows are skipped until the command lands.
- `enabled` stays a code function per tool (e.g. extrude needs a closed path), never a data field.
- The renderer draws tabs, groups, captions and cells from the spec; the group hue comes from
  `IconFamily`; the caption band is the dark strip.
- Height: 2 + 28 + 2 + 30 + 12 ≈ 74 → target 72 with the existing margins; collapsed = tab row 29.
- Keep the open state in settings (`ribbon.open`), default true, `#[serde(default)]`.
- Vocabulary is `furnicraft-text`: Эскиз, Модель, Мебель, Сцена, Вид; Создать, Изменить, Опорные,
  Размеры, Булевы; tool labels from the map.

## Tests

- every tab id, group id and tool id is unique;
- every `ToolAction` that exists appears exactly once;
- a planned tool is not drawn;
- a tab with no live tool is not drawn;
- the measured cell uses the widest group, not a constant;
- `height(true)` is 72 and `height(false)` is 29;
- the open state and the active tab round-trip through settings;
- the ribbon draws without a document (the context is a snapshot).

## Ruled out

- Keeping the three enums and adding arms: the map would still be code.
- One visible tool per group: `Создать` needs line and polyline side by side.
- A runtime JSON/TOML layout: not until level B (user panels).
