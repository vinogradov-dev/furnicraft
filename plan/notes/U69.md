# U69 — The sketch tool icons

The sketch tool icons

## List (name → what it shows)

| icon | drawing |
|---|---|
| trim | a line with a removed middle, a cut line crossing it and the removed piece dashed |
| extend | a short line, a dashed extension to a boundary, an arrow at the boundary |
| offset | a corner and its parallel copy, a short arrow between them |
| fillet | a sharp corner in dashes and the rounded corner in solid ink |
| chamfer | a sharp corner in dashes and the straight cut in solid ink |
| break | a line interrupted by a zigzag gap with two short dashes |
| construction-horizontal | a dashed horizontal line, end ticks, a reference dot |
| construction-vertical | the same turned 90° |
| construction-parallel | two parallel strokes and two witness ticks |
| construction-angle | two rays from a vertex and a dashed arc between them |
| dimension-linear | two extension lines, a dimension line with inward arrows |
| dimension-angular | two rays, an arc with two arrows |
| dimension-radius | an arc, a line from the centre with an arrow, a centre dot |
| boolean-union | two overlapping circles, both passive-filled, both outlines |
| boolean-subtract | the left circle solid, the right one dashed (removed) |
| boolean-intersect | two dashed circles and the lens filled |

Sizes and weights follow `STYLE_GUIDE.md` §7.3: construction guides 1.5, base 1.6–1.8, result
2.2–2.6; a result may carry the 0.45–0.60 fill. The draw role ink is #58C8DC (dark) / #1C7C92
(light); the result tone is the same ink at 0.45–0.60 alpha, never a second hue.

## Rules

- 24 × 24 grid, ink 3..21, coverage 20–45 % of the 18 × 18 footprint (the test in `icons.rs`).
- At most three inks; no gradients, masks, clip paths, text, CSS or filters.
- The shape must read with colour removed: build the meaning from weight, gap and mass.
- Trim/offset/fillet/chamfer share the "before in dashes" grammar, so the family reads as one set.
- Keep the published axonometry where the shape is volumetric; these sixteen are flat.

## Tests

- each file rasterises non-empty at 16/20/22 px and stays in the footprint and coverage band;
- only role hex values appear;
- the `ALL` list and the README table count agree;
- the empty-file fallback test still passes;
- eye review on the ribbon in both themes.

## Ruled out

- Copying the mock's exact paths: the mock is a sketch, not a source; redraw to this table.
- One generic "modify" glyph for all six edit tools: at 22 px the six must differ in shape, not hue.
- Reusing the `view` hue for dimensions: dimensions are a distinct family in the map (scene hue).
## What the session built (2026-11-12)

- The sixteen files exist under `assets/icons/contour/`: `trim`, `extend`, `offset`, `fillet`,
  `chamfer`, `break`, `construction-horizontal`, `construction-vertical`, `construction-parallel`,
  `construction-angle`, `dimension-linear`, `dimension-angular`, `dimension-radius`,
  `boolean-union`, `boolean-subtract`, `boolean-intersect`. The six edit tools and the four
  construction guides are `draw`; the three dimensions override to `scene` and the three booleans to
  `model` (the note's rule), so the family literal is what each master writes.
- Dashes are literal short paths, never `stroke-dasharray`: the README's paint list allows no other
  attribute, so a guide, a removed edge and a dashed input circle are several small `<path>`s.
  Weights: guides and dashes 1.5, inputs 1.6–1.8, results 2.2–2.6; fills are passive 0.12–0.15,
  except the boolean result (subtract disk 0.45, intersect lens 0.50–0.55).
- `crates/ui/src/icons.rs` declares one `Icon` per file and the count in
  `every_icon_uri_names_its_theme_and_file` moves 81 → 97. A new test,
  `the_readme_theme_table_lists_exactly_the_declared_icons`, parses the `README.md` theme row and
  compares it both ways with the `ALL` list, so the table and the macro cannot drift again.
- The twelve older contour files already carry `#58C8DC` and needed no re-inking: U70 moved every
  master to its family literal in the same pass that introduced `RoleRamp`.

### Review

U68's one-loop ribbon does not exist yet (U69 runs first), so the eye review used a throwaway
contact sheet of all 28 contour icons at 22 px in both variants, composed by the same role
substitution (`#58C8DC` → `#1C7C92` on paper) and deleted after the check. Two shapes were redrawn
after it: `break` gained end dots and lost the tall zigzag that read as a cross, and
`boolean-intersect` moved from four 45° dashes per circle to three 60° dashes so the lens and the
two dashed inputs separate at 22 px. The real ribbon is reviewed in U68, when it exists.

### Ruled out

- `stroke-dasharray` for the dashes: the README's paint list is closed, and the rasteriser's
  attribute set is the contract; several short paths cost nothing at this size.
- Re-inking the older contour files: U70 already wrote the draw literal into all of them, and the
  working tree shows no other hex.
- A per-icon family guess for dimensions: the note's rule is scene, and booleans are model; putting
  them in the theme's default draw would make them read as sketch geometry.
