# U69 — The sketch tool icons

The sketch tool icons

## List (name → what it shows)

| icon | drawing |
|---|---|
| trim | a line with a removed middle, a cut line crossing it and the removed piece dashed |
| extend | a short line, a dashed extension to a boundary, an arrow at the boundary |
| offset | a corner and its parallel copy, a short arrow between them |
| fillet | a sharp corner in dashes and the rounded corner in solid ink |
| chamfer | a sharp corner in dashes and the straight cut in solid ink |
| break | a line interrupted by a zigzag gap with two short dashes |
| construction-horizontal | a dashed horizontal line, end ticks, a reference dot |
| construction-vertical | the same turned 90° |
| construction-parallel | two parallel strokes and two witness ticks |
| construction-angle | two rays from a vertex and a dashed arc between them |
| dimension-linear | two extension lines, a dimension line with inward arrows |
| dimension-angular | two rays, an arc with two arrows |
| dimension-radius | an arc, a line from the centre with an arrow, a centre dot |
| boolean-union | two overlapping circles, both passive-filled, both outlines |
| boolean-subtract | the left circle solid, the right one dashed (removed) |
| boolean-intersect | two dashed circles and the lens filled |

Sizes and weights follow `STYLE_GUIDE.md` §7.3: construction guides 1.5, base 1.6–1.8, result
2.2–2.6; a result may carry the 0.45–0.60 fill. The draw role ink is #58C8DC (dark) / #1C7C92
(light); the result tone is the same ink at 0.45–0.60 alpha, never a second hue.

## Rules

- 24 × 24 grid, ink 3..21, coverage 20–45 % of the 18 × 18 footprint (the test in `icons.rs`).
- At most three inks; no gradients, masks, clip paths, text, CSS or filters.
- The shape must read with colour removed: build the meaning from weight, gap and mass.
- Trim/offset/fillet/chamfer share the "before in dashes" grammar, so the family reads as one set.
- Keep the published axonometry where the shape is volumetric; these sixteen are flat.

## Tests
